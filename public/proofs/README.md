## Image Format Guidelines

- **Format**: PNG, JPG, or WebP
- **Recommended Size**: 1200-1600px width for best quality
- **File Size**: Keep under 2MB per image for optimal loading
- **Quality**: Use high-quality screenshots that are clear and readable

## After Adding Images

1. Place all images in this `/public/proofs/` directory
2. The website will automatically display them in the Proof of Work section
3. Each image can be clicked to view in full-screen mode
4. Navigation arrows will appear when hovering over images (for galleries with multiple images)
